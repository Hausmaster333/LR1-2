# ЛР-1: AVL-дерево поиска

`BinarySearchTree<K, V>` (`../shared/include/tree/bst.h`): сбалансированное дерево поиска на своих `ShrdPtr`/`WeakPtr` из ДЗ-1 (в `../shared/include/ptr`).
`BinarySearchTree<K>` — множество ключей, `BinarySearchTree<K, V>` — словарь. На нём построены
`TreeSet<K>` (интерфейс `ISet`) и `TreeDictionary<K, V>` (интерфейс `IDictionary`).
Типы элементов: `int`, `double`, `std::string`, `Complex`, `Student`, `Teacher`.

Выбранные пункты задания:

| Пункт | Что сделано | Баллы |
|---|---|---|
| 1 | Вставка, поиск, удаление | 5 |
| 1.1 | AVL-балансировка | 2 |
| 1.2 | `map`, `where`, `reduce` (reduce в любом из 6 обходов) | 3 |
| 1.4.2 / 1.5.2 | Запись в строку и чтение из строки по формату `{К}(Л)[П]` | 3 + 4 |
| 1.6 / 1.7 | Извлечение поддерева, поиск вхождения поддерева | 2 + 3 |
| 7.1 – 7.3 | `ICollection`, `IEnumerable` + перечислитель по любой стратегии обхода (`get_enumerator(LevelOrder())`), операторы `[] += -= == !=` | 7 |

Итого 29 баллов.

## Сборка

Команды сборки и запуска обеих лабораторных приведены в [общем README](../README.md).

## Интерфейс

- **AVL-дерево поиска**: выбор типа элементов; ручной ввод и автозаполнение (количество, диапазон,
  seed); отрисовка дерева (по клику на узел значение подставляется в поле ввода, масштаб
  меняется по Ctrl + колесо); 6 обходов; map / where / reduce;
  поддеревья; строки в произвольном формате; журнал операций.
- **Бенчмарки**: замеры в фоновом потоке, сравнение с `std::set`, графики времени
  (общего и на один элемент), таблица, сохранение и загрузка CSV. Объёмы 10^7 – 10^8 удобнее
  считать консольным `benchmark`, а потом загрузить CSV в интерфейс.

## Замечания

- В примере `reduce` из задания арифметическая ошибка: `2*2 + 3*14 = 46`, а не 42, поэтому
  правильный ответ 144, а не 132 (см. тест `ReduceExampleFromTask`).
- Строка формата должна быть однозначной: вокруг каждой части есть ограничители, а ограничитель
  после поддерева не начинается с того же символа, что открывающий. `\` используется для
  экранирования.
- Если строка описывает корректное, но несбалансированное BST, при чтении оно перестраивается.
